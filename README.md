# Roguelike2D · 横板动作肉鸽

> **一句话简介**：一款 2D 横板动作 Roguelike。每次进入地牢，房间布局、敌人配置与掉落词条都会重新生成；死亡即失去本局所有收获，但可以用积累的资源永久解锁新武器与词条，形成「越玩越强、越强越想玩」的循环。

## 玩法

**已经能玩的**（当前可运行版本）

- **横板动作战斗**：近战挥砍带判定框与命中闪白、击退硬直；法师发射投射物，射手拉弓射箭
- **房间流水线**：清场 → 开门 → 换房，房间池用「袋子随机」抽，抽完一轮才重复
- **六种小怪**：哥布林（近战挥砍）/ 骷髅弓箭手（远程射箭）/ 史莱姆（弹跳撞击）/ 蝙蝠（空中扑咬）/ 火焰法师（远程火球）/ 持盾战士（举盾冲撞）；房间里的刷怪点**每局按种子随机换怪**，同一间房尽量六只各来一次，越往后的房间刷得越多
- **三名职业 + 技能栏**：战士（旋风斩 / 战吼）/ 法师（火球、回血法阵）/ 射手（多重射击、穿透箭、箭雨、猎人专注），技能走 `SkillData` 数据驱动
- **资源条**：血量 / 蓝量 HUD，技能进入冷却时技能栏实时反馈
- **大厅与暂停菜单**：启动先进**等待大厅**——一间铺满画面的**俯视**暗房间，三尊台子上站着战士 / 射手 / 法师，鼠标点角色立牌、确认之后**台上那个人就活过来变成你**（不是凭空冒出一个人）才能走动，走到门口按 `E` 出发（进关后是横板）；局内 `Esc` 随时暂停，可调主音量/音乐/音效、重绑 7 个按钮动作、返回大厅、退出游戏

**设计目标**（还没实现，见 [docs/00-行动清单.md](docs/00-行动清单.md)）

- **程序生成关卡**：敌人配置已经做到「每局随机 + 种子复现」（见 [docs/24](docs/24-怪物随机刷新与素材修复.md)），房间布局那半还没做
- **词条构筑**：局内获取遗物/词条，词条之间存在乘算联动，构筑决定强度上限
- **永久成长**：局外解锁新武器与词条，死亡不等于白玩
- **Boss 战**：多阶段 Boss，血量过半后变招

## 操作

默认绑定表就是 `Assets/_Project/Settings/PlayerInputActions.inputactions` 里的 8 个 Action（1 个 `Player` ActionMap / 17 条 binding）。除了直接改这个文件，也可以在游戏里 **`Esc` → 按键调整** 重新绑定，改完存进注册表（`PlayerPrefs`），下次启动自动生效，见 [docs/12](docs/12-Esc菜单与设置.md)。

| 按键 | 动作 | Action |
| --- | --- | --- |
| `A` / `D`（或 `←` / `→`） | 左右移动 | `Move` |
| `W` / `S`（或 `↑` / `↓`） | 上下（跳跃/下蹲预留） | `Move` |
| `Space` | 跳跃（含土狼时间与跳跃缓冲） | `Jump` |
| `LeftShift` | 冲刺 | `Dash` |
| `J` | 普通攻击（三段连击：劈砍 → 上挑 → 突刺） | `Attack` |
| `K` | 技能 1：战士**旋风斩**（转 1.2 秒，一直扫）／法师**火球术**（按住蓄力，越久球越大越快越疼）／射手**多重射击**（3 支箭扇形） | `Skill1` |
| `L` | 技能 2：战士**战吼**（震出一圈冲击波，把敌人吓跑）／法师**回复**（撑开法阵，2.4 秒内持续回血）／射手**穿透箭**（一支箭打穿 4 个敌人） | `Skill2` |
| `U` / `I` | 技能 3 / 4：战士暂无／法师暂无／射手**箭雨**（身前落 9 支箭，带落点预警）与**猎人专注**（6 秒攻速 +35%、暴击 +15%） | `Skill3` ~ `Skill4` |
| `Esc` | 暂停菜单（设置 / 按键调整 / **切换职业** / 返回大厅 / 退出游戏） | — |
| `Tab` | 背包与装备（点格子穿脱装备） | — |
| `E` | **仅在大厅**：走到门口出发（站在门口 0.8 秒也会自动出发） | — |
| 鼠标左键 | **仅在大厅**：点角色立牌选中 → 弹确认框 → 点「确认」才能走动 | — |
| `WASD` / 方向键 | **仅在大厅**：俯视四方向走动（确认角色之后才生效） | `Move` |

## 如何运行

### 方式一：直接下载（推荐给面试官 / 老师）

前往 [Releases](../../releases/latest) 下载 `Roguelike2D-v1.0-win64.zip`，解压后运行 `Roguelike2D.exe`。
无需安装团结引擎（打包还没做，链接先占位）。

### 方式二：从源码运行（需要改代码的队友看这里）

> 完整版见 [**docs/22-新同学上手指南.md**](docs/22-新同学上手指南.md)，下面是速查版。

**前置**：团结引擎 **1.10.4**（内部版本 `2022.3.62t16`）、Git、Git LFS。
**顺序不能反**——先装 LFS 再克隆，否则所有 png/wav 都会变成 130 字节的指针文本。

```bash
# 1. 启用 Git LFS（只需一次，全局生效）
git lfs install

# 2. 克隆（标准 HTTPS；只有你本机封了 22 端口时才改用
#    ssh://git@ssh.github.com:443/AwaKudsu/Roguelike2D-Tuanjie.git）
git clone https://github.com/AwaKudsu/Roguelike2D-Tuanjie.git
cd Roguelike2D-Tuanjie

# 3. 配置 SmartMerge / LFS / 自检忽略规则（幂等，可重复跑）
powershell -ExecutionPolicy Bypass -File Tools\setup-git.ps1
```

然后用 **团结 Hub → 添加工程 → 选择该文件夹**，使用 `2022.3.62t16` 打开（弹版本提示时选「用当前版本继续」，**不要**升级工程）。首次打开需要几分钟导入资源并重建 `Library/`。

打开后验收：`Console` 零红字 → 打开 `Assets/_Project/Scenes/Game.unity` → `Play` 能进大厅、选角色、出门打怪，才算真的跑起来了。

> 仓库不含 `Library/`、`Logs/`、`.codely-cli/`（团结 Cowork 的本地代码索引），这些都是本机可重建的缓存。

## 目录结构

```
Roguelike2D/
├── Assets/
│   ├── _Project/              # 所有自己产出的资源（下划线开头，排在资源浏览器最前）
│   │   ├── Art/               # 美术：角色 / 敌人 / 场景 / UI / 特效
│   │   ├── Audio/             # 音频：BGM / 音效
│   │   ├── Data/              # ScriptableObject 数据：武器 / 词条 / 敌人 / 房间
│   │   ├── Prefabs/           # 预制体
│   │   ├── Scenes/            # 场景
│   │   ├── Scripts/           # 代码，按职责分层
│   │   │   ├── Core/          # 游戏循环、状态机、事件总线、存档
│   │   │   ├── Player/        # 输入、移动、战斗
│   │   │   ├── Enemies/       # 敌人 AI 与感知
│   │   │   ├── Combat/        # 伤害、命中、状态效果
│   │   │   ├── Roguelike/     # 关卡生成、掉落、词条、局外成长
│   │   │   ├── UI/
│   │   │   └── Utils/
│   │   ├── Settings/          # 渲染 / 输入等配置资源
│   │   ├── Tests/             # 单元测试
│   │   └── UI/
│   └── ThirdParty/            # 第三方免费素材，每个包必须带 SOURCE.md 标注授权
├── docs/                      # 设计文档、开发清单、Git 手册、迁移记录
├── Tools/                     # 开发辅助脚本
├── Packages/                  # 包依赖清单
├── ProjectSettings/           # 工程设置（必须提交）
└── _Tuanjie/                  # 迁移自检报告与设置备份（54 MB 的安装清单不入库）
```

`Assets/_Project/_Tuanjie/` 下有一个编辑器专用目录，装的是迁移期的自检工具 `Editor/MigrationVerifier.cs`（菜单 `团结/`）：跑一遍会输出脚本编译、预制体、场景引用、内置资源等检查报告到 `_Tuanjie/`，用来在迁移后证明「没有断引用、没有 Missing Script」。它不是游戏逻辑，可以随时删掉。

**为什么这么分**：`Assets` 根目录下的东西越少越好。所有自己的东西塞进 `_Project/`，第三方素材塞进 `ThirdParty/`，以后要删素材包、要迁移、要给别人看代码，都不会误伤。

## 我做了什么

<!-- 这段是给面试官看的，务必用「我」做主语，不要写「我们」 -->

- 设计并实现了基于**房间池资产（`ScriptableObject`）+ 权重与出现窗口**的关卡流水线，所有抽样走固定种子的 `System.Random`，同一个种子必然生成同一套关卡顺序（可写单元测试验证）
- 实现了数据驱动的词条系统（`ScriptableObject` + 数值修饰管线），新增词条无需修改战斗代码
- 实现了背包与三槽装备系统（武器 / 护甲 / 饰品）：物品同样是 `ScriptableObject`，穿上后走同一条数值修饰管线；武器还能接管普通攻击形态（法杖换成远程弹道），见 [docs/13-Day9背包与装备.md](docs/13-Day9背包与装备.md)
- 背包界面按「造梦西游」式布局重做：**左上人物立绘**（取职业图标，没图就整块隐藏）、**左下十行属性表**（全部走 `CharacterStats`，穿脱装备立刻反映）、**右侧 `全部 / 武器 / 护甲 / 饰品` 分类标签 + 物品网格**；格子里的文字与图标先算好各占多少像素，装备没有图标时用稀有度色块顶上，见 [docs/21-背包界面重做.md](docs/21-背包界面重做.md)
- 实现了角色动作手感细节：土狼时间、跳跃缓冲、可变跳跃高度、冲刺（含无敌帧与冷却）
- 把一张「骑士姿势总表」抠图切成 16 张帧、再派生出 11 张过渡帧（共 27 张帧），按几何关系接进角色，用代码状态机驱动待机呼吸/6 帧跑动/跳/冲刺/三段连击（起手 → 命中 → 收招）/横扫/受击/死亡/胜利；普通攻击的三段连击判定框与击退各不相同，刀光**不用任何贴图**——每帧记下剑扫到哪，把这些点连成一条网格亮痕（扫得快就宽、剑停下就消失），见 [docs/14-战士素材与动作.md](docs/14-战士素材与动作.md)、[docs/16-更多动作帧.md](docs/16-更多动作帧.md) 与 [docs/17-刀光按剑轨迹现画.md](docs/17-刀光按剑轨迹现画.md)
- 战士的两个技能做成了真机制：**旋风斩**持续 1.2 秒、每 0.2 秒扫一次（后走进圈里的敌人也会被扫到）；**战吼**从自身炸出一圈冲击波，半径内的敌人丢掉攻击目标、背对着你来回乱跑 3.5 秒。见 [docs/15-战斗表现与战吼.md](docs/15-战斗表现与战吼.md)
- 把第二个职业做出来了：法师的姿势表同样抠图切成 **21 张帧**，两套动画挂在一个 `IPlayerAnim` 接口后面，技能层不用知道玩家是谁；法师的**回复**会举杖撑开法阵、每 0.3 秒回一次血并在头顶飘绿字，**火球**支持长按蓄力（1.1 秒蓄满，球 2.2 倍、速度 1.9 倍、伤害 2.0 倍，扣蓝放在松手那一刻），见 [docs/18-法师素材与技能.md](docs/18-法师素材与技能.md)
- 把第三个职业做出来了：射手。姿势表同样是切好的帧（**16 张**，448×672 / 224 PPU），
  核心动作是「拉弓」而不是挥砍，所以普通攻击和三个输出技能共用一段 3 帧射击序列。
  弓手的两类新技能撑开了数据层：**箭雨**（身前 5 单位处撒 9 支箭、带落点预警圈，
  靠 `ProjectileLauncher.FireDirected` 垂直向下发射，速度与存活时间单独覆盖）和
  **猎人专注**（只往 `CharacterStats` 挂 6 秒修饰符：攻速 +35%、暴击 +15%，一行攻击代码都没改）；
  大厅也随之变成**战士 / 射手 / 法师**三选一，见 [docs/23-射手角色与大厅三选一.md](docs/23-射手角色与大厅三选一.md)
- 用 Git 管理项目，配置 UnityYAMLMerge 作为场景/预制体的合并驱动，处理 `.unity` 与 `.prefab` 的多人协同时的冲突
- 做了「元气骑士」式的**等待大厅**：不是弹一层卡片，而是在场景左侧搭了一间**铺满画面的俯视暗房间**。房间、地砖、墙砖、地毯、挂毯、石台、火把、石柱、出口石拱这 **10 张图全部程序化绘制**（`D:\tjart\lobby\make_lobby_art.py`，PIL 按像素点画，配色对齐骑士/法师素材），只有三个角色立绘用他们自己的帧。鼠标点角色 → 确认框 → **台上那人解除雕像状态变成玩家**、才能四方向走动，走到门口出发；确认前玩家隐藏且不能动，大厅期间横板控制器与战斗全关、相机对准房间正中，出门全部还原。地板铺得比房间大一圈，任何窗口比例都不会露出相机底色；大厅与关卡共用一个场景（玩家不是预制体），靠 `RoomManager.SuspendForLobby / StartRunFromLobby` 隔开，见 [docs/20-元气骑士式大厅.md](docs/20-元气骑士式大厅.md)
- 把工程从 Unity 6000.3 迁移到团结引擎 2022.3（含 22 处 API 降级与内置资源引用重映射），全程保持原 Unity 工程零改动，见 [docs/09-迁移到团结引擎.md](docs/09-迁移到团结引擎.md)
