# Day 9 · 背包与装备

> 目标：背包里能放东西，点一下就能把武器 / 护甲 / 饰品穿上，属性立刻生效，再点一下脱下来。
> 全部改动都在团结工程 `D:\TuanjieRoguelike2D` 里，Unity 侧 `D:\Roguelike2D` 一个字节没动。

## 2. 数据结构

```csharp
public enum EquipSlot { Weapon = 0, Armor = 1, Trinket = 2 }
public enum ItemRarity { Common, Rare, Legendary }

public class ItemData : ScriptableObject
{
    public string displayName;
    public string description;
    public Sprite icon;
    public ItemRarity rarity;
    public EquipSlot slot;
    public AttackData weaponAttack;      // 只有武器用：留空＝沿用角色当前攻击
    public StatModifier[] modifiers;    // 复用词条系统那套修饰符
}
```

`StatModifier` 是词条系统早就有的结构（`StatTypes.cs`）：`StatType` + `ModifierMode`（`Flat` / `PercentAdd` / `PercentMultiply`）+ `Value`。
**装备和词条走的是同一条数值链路**，所以：

```
CharacterStats.Get(StatType) = flat × (1 + percentAdd) × percentMul
```

攻击力、生命上限、防御、冷却缩减、法力、回蓝……所有消费点都不用改一行代码。`ItemData.DescribeModifiers()` 用它来生成「攻击力 +6 / 暴击率 +5%」这种文案，界面里直接显示。

## 3. 穿戴链路

```
点格子 (ItemSlotWidget.OnPointerClick)
  └─ InventoryUI.HandleClick
       ├─ 装备槽 → Equipment.Unequip(slot)
       └─ 背包格 → Equipment.Equip(item)
            ├─ inventory.Remove(item)           // 先从背包拿走
            ├─ Clear(旧装备)                     // ★ 撤掉旧装备的全部修饰符
            ├─ _equipped[slot] = item
            ├─ Apply(item)
            │    ├─ stats.AddModifier(modifier, item)   // source = 这件装备
            │    └─ 武器槽：attacker.SetAttack(item.weaponAttack ?? 出厂攻击)
            └─ inventory.Add(旧装备)             // 旧的回背包
```

三处顺序是有讲究的：

1. **先 `Remove` 新装备再 `Add` 旧装备** —— 反了的话背包正好满时会「旧的放不回去、新的也没穿上」。
2. **`Clear(旧装备)` 必须在 `Apply(新装备)` 之前** —— 否则两件的加成会叠加，而且旧装备已经不在槽位里，以后再也没有机会被清掉（这个坑真踩过，见 §6）。
3. **脱下时背包满了就拒绝** —— 而不是把物品凭空丢掉。

`RemoveAllFrom(item)` 靠 `source` 参数精确撤回，所以同一条词条 / 两件不同装备的修饰符互不干扰。

## 4. 六件示例物品

| 物品 | 稀有度 | 槽位 | 效果 |
| --- | --- | --- | --- |
| 铁剑 `Item_IronSword` | 普通 | 武器 | 攻击力 +6 |
| 橡木法杖 `Item_OakStaff` | 稀有 | 武器 | 攻击力 +10%、暴击率 +5%，普通攻击换成 `Attack_MageBolt`（远程） |
| 皮甲 `Item_LeatherArmor` | 普通 | 护甲 | 最大生命 +25、防御 +5% |
| 法袍 `Item_Robe` | 稀有 | 护甲 | 最大法力 +30、每秒回蓝 +2、防御 +3% |
| 力量指环 `Item_PowerRing` | 稀有 | 饰品 | 攻击力 +15% |
| 学者护符 `Item_ScholarAmulet` | 传说 | 饰品 | 冷却缩减 +10%、暴击伤害 +20% |

初始背包里放了 4 件（铁剑 / 皮甲 / 力量指环 / 橡木法杖），容量 12。

**武器换形态**是这套系统里唯一改战斗行为的部分：`PlayerAttacker.SetAttack(AttackData)` 这个接口其实 Day 5 就写好了（注释就写着「换武器时改的就是它」），但一直没人调用 —— 现在装备系统把它接上了。脱下武器时会还原成 `Awake` 时记下的「出厂攻击」。

## 5. 怎么用

1. 进 Play，按 `Tab`（或点右下角提示）打开背包。
2. 左侧三个大方格是装备槽（武器 / 护甲 / 饰品），右边 4×3 是背包格。
3. **点背包里的物品**＝穿上；**点装备槽里的物品**＝脱下。鼠标悬停会出提示框（名字、稀有度、效果）。
4. 打开背包时游戏暂停（走 `TimeFreeze`，和词条面板共用一套仲裁，不会互相解冻），`Esc` 或再按 `Tab` 关闭。
5. 换武器后去打一下敌人，能看到普通攻击的变化（法杖会射出投射物）。

## 6. 自检（不按 Play）

`EditorApplication.EnterPlaymode()` 在 `-batchmode` 下会挂在 `Temp/__Backscenes` 上不返回，所以自检走的是**反射调 `Awake()` 再直接调业务方法**：

```powershell
Tuanjie.exe -batchmode -quit -projectPath D:\TuanjieRoguelike2D `
  -executeMethod Tuanjie.PortCheck.Day9Check.Run `
  -logFile D:\TuanjieRoguelike2D\_Tuanjie\day9-check.log
```

报告写在 `_Tuanjie/day9-check-report.txt`。最近一次结果：**通过 41 / 失败 0**

```
[INFO] 基线 | 攻击 13 / 生命 140 / 防御 0.1 / 法力 60
[PASS] 穿铁剑 → 攻击 +6 | 实际 19 / 期望 19
[PASS] 换橡木法杖 → 攻击 +10% | 实际 14.3 / 期望 14.3
[PASS] 法杖接管普通攻击 | Attack_MageBolt
[PASS] 铁剑被自动退回背包 | 同槽位旧装备回收
[PASS] 脱武器 → 攻击力还原 | 实际 13 / 期望 13
[PASS] 穿皮甲 → 生命 +25 | 实际 165 / 期望 165
[PASS] 换法袍 → 生命回到基线 | 实际 140 / 期望 140
[PASS] 戴力量指环 → 攻击 +15% | 实际 14.95 / 期望 14.95
[PASS] 换学者护符 → 指环加成消失 | 实际 13 / 期望 13
[PASS] 背包能装满 | 12/12
[PASS] 第 13 件被拒绝 | 容量上限生效
```

### 事故记录：换装时旧装备的加成没有撤掉

第一版 `Equipment.Equip()` 只做了「换槽 + Apply 新装备 + 旧装备回背包」，**忘了 `Clear(old)`**。自检立刻抓出来：

```
[FAIL] 换橡木法杖 → 攻击 +10% | 实际 20.9 / 期望 14.3     ← (13 + 6) × 1.1，铁剑的 +6 还赖着
[FAIL] 脱武器 → 攻击力还原 | 实际 19 / 期望 13
[FAIL] 换法袍 → 生命回到基线 | 实际 165 / 期望 140         ← 皮甲的 +25 也赖着
```

这类错误**在 Play 里几乎不可能靠肉眼发现**（数值差 6 点，敌人血量又不是整数），是自检最有价值的地方。修法就是在 `Apply(item)` 之前加一行 `if (old != null) Clear(old);`。

## 7. 排错表

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 按 `Tab` 没反应 | 场景里没有 `InventoryUI`，或它没被启用 | 重跑「团结 → 生成背包与装备物品」 |
| 界面出来了但格子是空的 | 背包是空的（初始物品在 `Inventory.startingItems` 里，Play 时才灌进去） | 看 Player 的 `Inventory` 组件，或先跑一次生成菜单 |
| 点了物品没反应 | 该格子没有 `ItemSlotWidget`，或 `GraphicRaycaster` 丢了 | 检查 Canvas 上有没有 `GraphicRaycaster` |
| 穿上装备属性没变 | `Equipment.stats` 没接 | 选中 Player → `Equipment` → `Stats` 拖进 `CharacterStats` |
| 换武器后敲不出远程 | 法杖的 `weaponAttack` 为空 | 选中 `Item_OakStaff`，把 `Attack_MageBolt` 拖进 `Weapon Attack` |
| 打开背包时游戏还在动 | `TimeFreeze` 被别的窗口抢先解冻 | 只可能是有其它代码直接写 `Time.timeScale`，全工程应该只有 `TimeFreeze` 写它 |
| 文字显示成方块 | 系统没有中文字体 | 装微软雅黑 / 黑体，或改 `InventoryUI.UiFont` 的字体名数组 |

## 8. 已知限制 / 下一步

- **没有拖拽**：现在是「点一下穿 / 点一下脱」，不做鼠标拖拽。拖拽要处理 `IBeginDragHandler`、`IDropHandler` 和一堆边界情况，性价比低。
- **没有丢弃与出售**：物品只能穿、脱、放在背包里，没有删除入口（局内货币和商店在阶段 3）。
- **没有掉落**：敌人死后不掉装备，物品目前只有初始那 4 件 + 手动往场景里加的。等 Day 10 做房间奖励时接上。
- **饰品槽只有一个**：三个槽位是武器 / 护甲 / 饰品各一，没有「双戒指」。
- **图标是纯色块**：工程里还没有美术资源，界面上的图标都是用 `ItemData.icon`（留空就用纯色块 + 稀有度配色）。
- **下一步**：回到关卡流程 —— 打完一间房出 2~3 个门，按 `RoomType`（战斗 / 精英 / 商店 / 宝箱 / BOSS）选下一间。
