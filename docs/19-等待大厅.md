# Day 19 · 等待大厅（选角色再开局）

> ⚠️ **已作废**：这一版的大厅是一层全屏卡片（两张职业卡点一下开局）。
> 之后按要求改成了「元气骑士那种」——场景里能走动的房间，走到台子前按 `E` 选人、走到门口出发。
> 现行实现与代码位置见 **[docs/20-元气骑士式大厅.md](20-元气骑士式大厅.md)**；本文只留作历史记录。

大厅就是「元气骑士」那种：进游戏先站在一个房里，挑角色、看属性，点了「开始游戏」才真正下去打。

## 1. 为什么不是把暂停菜单那个「大厅」页放大

`GameMenuUI` 里其实已经有一页叫「大厅」（暂停后点「返回大厅」会回到那里）。但它和真正的等待大厅不是一回事：

| | 暂停菜单的「大厅」页 | 这次的等待大厅 |
| --- | --- | --- |
| 什么时候出现 | 局内按 Esc 之后 | 开局之前 |
| 主要用途 | 继续 / 设置 / 改键 / 退出 | 选职业、看数值、看技能 |
| 信息密度 | 一列按钮 | 两张卡片 + 头像 + 六项属性 + 技能表 |

硬塞进一个界面会出现「暂停着还能选角色」这种说不通的状态，所以**各做一套**：
`GameMenuUI`（排序 400）管局内，`LobbyUI`（排序 350）管开局前。

## 2. 它是怎么被装起来的

大厅是**运行时用代码搭的**，场景里没有它的任何物体 —— 和 `RelicChoiceUI`、`InventoryUI`、`GameMenuUI` 同一套做法。

理由还是那条：中文字形只在系统字体里（`Font.CreateDynamicFontFromOSFont`），它不是资产，序列化不进场景；再加上要摆几十个 `Image` / `Text`，手搭要拖几十次引用。

链路：

```
GameBootstrap.Boot()                    // [RuntimeInitializeOnLoadMethod(AfterSceneLoad)]
  ├─ GameSettings.Load()
  ├─ new GameObject("__GameMenu") + DontDestroyOnLoad
  ├─ AddComponent<GameMenuUI>()         // 局内暂停菜单
  ├─ AddComponent<LobbyUI>()            // 等待大厅
  └─ HandleScene() → ShowLobbyOnStart ? Lobby.Show() : Lobby.Hide()

LobbyUI.StartGame()
  ├─ FindObjectOfType<PlayerVisualSwitcher>().SetClass(选中的职业)
  │     └─ CharacterStats.ApplyClass → ClassChanged
  │           ├─ PlayerAttacker 换成该职业的普通攻击
  │           ├─ SkillCaster   换成该职业的技能栏
  │           └─ PlayerVisualSwitcher.ApplyForClass 开关两套动画 + 换待机图
  ├─ Hide()                             // 解冻时间、把输入还给玩家
  └─ GameBootstrap.StartRun()           // ShowLobbyOnStart = false
```

「返回大厅」走的是另一条：`GameBootstrap.ReturnToLobby()` 重新加载场景 → `sceneLoaded` → `HandleScene()` → 大厅又盖上来。所以大厅不需要「复位」，重载场景本身就是复位。

## 3. 界面上有什么

- 标题「肉鸽 2D」+「选一个职业，然后下去」
- 每个职业一张卡片（460 × 640）：
  - 头像（`ClassData.icon`，没配就回落到该职业待机动画的第一帧）
  - 职业名
  - 一句话定位（`ClassData.description`）
  - 六项属性：生命 / 攻击 / 移速 / 法力 / 暴击 / 防御
  - 技能表（按 K / L / U / I 顺序列出 `startingSkills`）
  - 左上角序号 `1` / `2`
- 选中的卡片：金色描边 + 背景变暖 + 放大到 1.03 倍（没选中缩到 0.98，靠尺寸差把注意力拉过去）
- 「开始游戏 · 法师」按钮（金色底、深色字，文案跟着选择变）
- 右下「退出游戏」，左下操作提示，底部版本号

## 4. 键盘与鼠标

| 操作 | 键 |
| --- | --- |
| 换职业 | `A` / `D`、`←` / `→` |
| 直选第 1 / 2 个 | `1` / `2` |
| 开始游戏 | `Enter` / `Space` |
| 点卡片 | 选中并直接开始（点两张卡就是「选它，走」） |

用 `Keyboard.current` 读键，和 `InventoryUI`（Tab）、`GameMenuUI`（Esc）一致 —— 全程走 Input System，没有 `Input.GetKey`。

## 5. 冻结与输入

进大厅时：

- `TimeFreeze.Freeze(this)` —— 世界不动。**不能直接写 `Time.timeScale = 0`**：暂停菜单、词条三选一也各有自己的冻结，谁后关谁说了算会导致另一个弹窗被提前解冻（`TimeFreeze` 就是为这个做的登记表）。
- `PlayerInputReader.enabled = false` —— 否则选角色时按 A / D 人就在后台跑了。

离开大厅（`Hide()`）两件事都反着做一遍。自检里专门验了这条：`[PASS] 离开大厅解冻`、`[PASS] 离开大厅恢复输入` —— 如果只冻结不还原，「开始游戏」就是假的。

## 6. 顺带修的两件事

### 6.1 火球打出去什么都没有（引用抄错的教训）

前一版把 `Fireball.prefab` 的贴图从占位圆换成 `Mage_Fireball` 时，guid 是我从 `.meta` 里抄的：

```
guid: DSke5y6tAHMf/QEnx80upAdlY2WIOHel/uVzhe0z1ZmV+zzx4YzCPVE=
```

看上去很像 guid，但它**不是工程里真正的 guid**。真正的 guid 要用编辑器问出来：

```
AssetDatabase.AssetPathToGUID("Assets/_Project/Art/Characters/Mage/Mage_Fireball.png")
→ 2c1b40c874f36f545b04a98f73c2cd2f
```

抄错的结果不是报错，是 `SpriteRenderer.sprite = null` —— 火球照常生成、照常飞行、照常打伤害，就是**看不见**。

**规则**：手改 YAML 里的 `guid:` 之前，必须用 `AssetDatabase.AssetPathToGUID` 拿 32 位 hex，不要从 `.meta` 里复制。
（顺带一提，`.meta` 里那一长串 base64 是团结自己的一种表示，和引用用的 hex guid 不是同一个字符串，也不是它的编码。）

自检里因此加了一条更容易抓的断言：

```
[PASS] 火球预制体贴图 | Mage_Fireball
```

以前的断言只比 `flipX`，贴图为 null 时照样过 —— **比「朝向对不对」更该先比「有没有图」**。

### 6.2 大厅按钮的一个坑

按钮最初是「同一个物体上既挂 `Image` 又挂 `Text`」，直接抛异常（Unity 里 `Graphic` 互斥，一个物体只能有一个）。改成底图一个物体、文字一个子物体就好了。这条记在排错表里。

## 8. 排错表

| 现象 | 原因 | 怎么查 |
| --- | --- | --- |
| 大厅里还能走动 | `PlayerInputReader` 没被关，或 `Hide()` 之后没还原 | 看自检的「进大厅会关掉玩家输入」 |
| 点开始游戏卡住 / 世界还是冻的 | `Hide()` 没走到，`TimeFreeze` 里还留着大厅这个 owner | 自检的「离开大厅解冻」 |
| 卡片是空白 | `ClassData.icon` 没配、且职业没有对应的 `*Visual` 组件 | 自检的「头像已接」 |
| 加按钮时抛 `Can't add 'Image' ... already added 'Text'` | 一个物体上挂了两个 `Graphic` | 拆成底图 + 文字两个物体 |
| 大厅被暂停菜单挡住 | `sortingOrder` 比 400 大 | `LobbyUI.SortingOrder = 350` |
| 选完职业进游戏人还是原来那套动画 | `PlayerVisualSwitcher.OnEnable` 没订阅上，`ClassChanged` 没人接 | 换职业时看 Console 有没有 `[PlayerVisualSwitcher] 当前职业：…` |

## 9. 已知限制

1. 大厅只是开局前的覆盖层，**没有独立的场景**（所以谈不上「在大厅里走动」）。
2. 点卡片会直接开始游戏，没有「先选中、再点开始」两步确认 —— 想只选中就点空白处（暂未做）。
3. 职业卡片最多摆 4 张（`Mathf.Clamp(..., 0, 4)`），加第三个职业时布局要重算。
4. 头像用的是待机第一帧，不是专门的立绘。
5. Esc 在大厅里没有绑定（怕误退），退出只能点「退出游戏」。
6. 大厅不记「上次选的是谁」：重进游戏会回到场景里配的默认职业。
