# Day 12 路 射手角色与大厅三选一

> 目标：把 `TuanjieRoguelike2D-1`（只多实现了射手）里已经调好的**射手**整套搬进本工程，
> 并让大厅从「两尊雕像」变成**战士 / 法师 / 射手**三选一。
> 主体（大厅、法师、装备、词条）一律不动，射手按现有的 `ClassData` + `SkillData` 管线加进去。

---

## 1. 射手在数值与技能上的定位

| 项 | 值 | 为什么 |
| --- | --- | --- |
| 生命 | 95 | 比法师（85）耐一点，比战士（140）脆得多 —— 远程职业不该能站桩 |
| 攻击 | 11 | 和法师持平；靠攻速与暴击拉开差距 |
| 移速 | 8.5 | 全场最快的一档，逃生靠腿 |
| 攻速 | 1.15 | 普攻 0.34 秒 ÷ 1.15 ≈ 0.30 秒一发，站着不动时 DPS 只在贴脸缠斗时吃亏 |
| 暴击 | 10% / ×1.6 | 配合「猎人专注」+15% 暴击后进入 25% |
| 法力 | 80 / 7 每秒 | 蓝量最少，逼玩家在「多重射击」和「箭雨」之间做取舍 |

四个技能对应 `K / L / U / I`：

| 键 | 技能 | 施放方式 | 机制 |
| --- | --- | --- | --- |
| `K` | 多重射击 | `Projectile` | 一次 3 支箭、扇形 ±10°，每支 80% 攻击力 |
| `L` | 穿透箭 | `Projectile` | 单支贯穿箭，`pierce` 最多打 4 个，220% 攻击力，箭速 26 |
| `U` | 箭雨 | `ArrowRain` | 身前 5 单位处撒 9 支箭，落点区域宽 8、持续 1.2 秒，落点有预警圈 |
| `I` | 猎人专注 | `Buff` | 6 秒内攻速 +35%、暴击率 +15%，脚下亮一圈金色光环 |

## 2. 为了搬这三样，改了哪些「公共管线」

射手不是只加一个 `ArcherVisual` 就完事 —— 它用到两种本工程此前没有的施放方式，
所以公共层必须一起扩：

| 文件 | 改动 | 为什么必须改 |
| --- | --- | --- |
| `Skills/SkillData.cs` | 枚举**追加** `ArrowRain`、`Buff`；新增 `rain*` 与 `buff*` 两组字段 | `castType` 是按整数存的，往中间插一项等于把所有已有技能错位一格，所以只能追加 |
| `Skills/SkillCaster.cs` | 加 `SkillCast` 事件；加 `CastArrowRain` / `CastBuff`；`ResetRoomState` 收掉箭雨与专注 | 普通攻击有 `PlayerAttacker.AttackStarted` 通知外观层，技能没有对应的出口，射手的拉弓姿势就播不出来 |
| `Combat/ProjectileLauncher.cs` | 抽出 `FireDirected`（任意方向发射），`Fire` 变成它的一层壳 | 箭雨的方向是垂直向下，不是「朝左/朝右」；速度与存活时间也要单独覆盖 |
| `Skills/Projectile.cs` | `Launch` 加 `speedOverride` / `lifeTimeOverride` | 同一个箭预制体既要当普攻（快、短），又要当箭雨（慢、从天而降） |
| `Player/PlayerVisualSwitcher.cs` | 从「两套动画」扩到「三套」；`Look` 枚举 + `IsWarrior/IsMage/IsArcher` | 三套组件每帧都往同一张 `SpriteRenderer` 上写图，不统一开关就会抢帧 |

新增的三个脚本：

- `Player/ArcherVisual.cs` —— 状态机（死亡 > 受击 > 射击 > 冲刺 > 专注 > 胜利 > 空中 > 行走 > 待机），
  实现 `IPlayerAnim`，所以技能层不需要知道玩家是射手；
- `Skills/ArrowRainCast.cs` —— 按时间撒箭 + 落点预警圈 + `StopNow()`（换房间时回收）；
- `Skills/HunterFocus.cs` —— 往 `CharacterStats` 挂修饰符，到期自己撤，不写一行攻击代码。

## 3. 射手为什么能「零场景改动」接进技能层

`PlayerAttacker` 只管普通攻击，`SkillCaster` 只管技能，两者都通过
`ClassChanged` / `SkillCast` 对外广播 —— 表现层订阅就够了。
所以射手换上去之后：普攻自动变成 `Attack_Arrow`（远程，走 `Projectile`），
技能栏自动换成四个射手技能，`ArcherVisual` 只要跟着播「拉弓」即可。

`ArcherVisual` 和另外两套还有一个必须处理的细节：**一帧都不能在大厅里写 sprite**。
`PlayerVisualSwitcher.SetLobbyMode(true)` 会把三套动画全部 `enabled = false`，
大厅里的朝向由 `LobbyAvatar` 决定；出发时再按当前职业打开对应那一套。

## 4. 大厅的第三尊立牌

原来两尊台在 `x = 6.6 / 13.4`（房间内部 20 宽）。加第三尊之后均匀摆成 **4.6 / 10.0 / 15.4**：

| 项 | 值 |
| --- | --- |
| 台座 | 复制 `Pedestal_Mage` 整棵子树（台座 + 立绘 + 光圈）后改名 `Pedestal_Archer` |
| 职业 | `Class_Archer.asset` |
| 立绘 | `Archer_Idle.png`（和战士、法师一样用待机帧，320 宽的画布统一对齐脚底） |
| 顺序 | `pedestals` 数组 = 战士 → 射手 → 法师，和 `PlayerVisualSwitcher.classes` 一致 |
| 职业表 | 追加 `Class_Archer`，`currentIndex` 仍从战士开始 |

大厅的选人流程（点立牌 → 确认框 → 台上那人活过来）一行代码都不用改：
`LobbyRoom` 本来就是遍历 `pedestals` 数组，数组多一项就多一个可选职业。

> ⚠️ 大厅朝向：射手只画了侧视姿势表，没有 `_Front / _Back` 图，
> 所以 `Class_Archer.lobbyFront` 直接填侧视待机帧 —— 和战士一个处理方式，
> `LobbyAvatar` 在缺图时会自动退回侧视，不会出现空白人。

## 5. 资源与工具

| 资源 | 来源 | 规格 |
| --- | --- | --- |
| `Art/Characters/Archer/*.png`（16 张） | 从一号工程原样拷入 | 448×672、224 PPU、Point / FullRect / 无压缩 |
| `Art/VFX/Arrow_Projectile.png` | 同上 | 192×64、320 PPU、箭头朝 +X |
| `Art/UI/Icons/Icon_*.png`（7 张） | 同上 | 职业卡 / 多重射击 / 弓 / 箭袋 / 专注 / 箭 / 战士卡 |
| `Data/Weapons/Attack_Arrow*.asset`（4 个） | 本工程重新写 | 射击 / 多重箭 / 穿透箭 / 落箭 |
| `Data/Skills/Skill_MultiShot / PiercingArrow / ArrowRain / HunterFocus` | 同上 | 注意 `castType` 用的是本工程的编号（`ArrowRain = 4`、`Buff = 5`） |
| `Prefabs/Arrow.prefab`、`ArrowPiercing.prefab` | 照 `Fireball.prefab` 的结构 | 只换贴图与参数，`Projectile` 脚本是同一个 |

生成与校验脚本放在 `Tools/archer-port/`：

| 脚本 | 作用 |
| --- | --- |
| `gen_assets.py` | 生成四个攻击、四个技能、职业资产与两个箭预制体（含 `.meta` 的 hex guid） |
| `patch_scene.py` | 给 `Game.unity` 挂 `ArcherVisual`、把射手接进 `PlayerVisualSwitcher`、复制出第三尊立牌 |
| `verify_refs.py` | 静态校验：fileID 不重、本地引用不悬空、hex guid 都能对上、职业→技能→攻击→预制体的链接完整 |
| `compile_check.ps1` | 用团结自带的 Roslyn 直接编译 `Assembly-CSharp` / `Assembly-CSharp-Editor`，不启动编辑器也能查语法与类型错误 |

> 这三个 Python 脚本是**一次性迁移工具**，正常改动请直接在编辑器里做；
> 重新跑 `patch_scene.py` 会先检测到场景里已有 `ArcherVisual` 并直接退出，不会重复挂组件。

## 6. 自检清单（在编辑器里跑 `团结/` 菜单时看）

- `团结/检查元气骑士式大厅`：立牌 ≥ 3 座，其中必须有一座是射手；
- `团结/检查法师`：职业表 ≥ 3 项、三套动画都实现 `IPlayerAnim`、切换器三个引用都指到了；
- 进游戏：大厅点射手 → 确认 → 走到门口 → `K` 三连射、`U` 箭雨落在身前、`I` 脚下亮光环且攻速明显变快；
- `Esc → 切换职业` 三次能回到战士（战士 → 法师 → 射手 → 战士）。
