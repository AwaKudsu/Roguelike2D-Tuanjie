# Day 20 · 元气骑士式等待大厅

> 之前的大厅是一层**全屏卡片**：两张职业卡摆在屏幕中央，点一下就开始。
> 你要的是「元气骑士那种」——一间能走动的房间，走到角色台前选人，走到门口出发。
> 这一版真的在场景里搭了那间房。

---

## 1. 现在的大厅是什么样

进 Play 之后，玩家被放进一间离关卡很远的房间（世界坐标 x ≈ -70 ~ -10）：

```
        ┌──────────────────────────────────────────────────────┐
        │                                                      │
        │      [台子]      [台子]                    ┌────┐     │
        │      战士        法师                      │ 门 │     │
        │  ▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔  ▔▔▔▔│    │▔▔▔  │
        └──────────────────────────────────────────────────────┘
     -70                      -52        -42              -18
```

| 位置（世界 x） | 是什么 |
| --- | --- |
| -70 ~ -10 | 大厅整间房（地板 3 段各 20 宽，`Ground` 层 + `BoxCollider2D`） |
| -62 | 玩家进大厅的出生点 |
| -52 / -42 | 两个角色台：战士 / 法师 |
| -18 | 传送门（两根柱子 + 门板 + 地面光圈） |

走动、选人、出发都在这间房里完成：

1. 进大厅 → 玩家站在出生点，右下角提示「A / D 走动 · 走到角色台前按 E」
2. 走近某个台子 → 台座被顶起来一点、变亮、光圈亮起，提示变成「按 E 选择 法师」
3. 按 E → **玩家的形象立刻换成那个职业**（不用等开局才知道选的是谁），门板从灰变金
4. 走到门口 → 提示「按 E 出发」，按 E → 建出第一间房、玩家被放到关卡出生点

> 大厅里攻击和技能是关着的（`PlayerAttacker.enabled = false`、`SkillCaster.enabled = false`），
> 免得在选人的时候往墙上放火球。

## 2. 为什么另搭一间房，而不是再做一个界面

| 做法 | 问题 |
| --- | --- |
| 全屏卡片层（上一版） | 选人时只能看不能动，进游戏像连按两次按钮；看不出角色在场景里的实际大小 |
| 新开一个 `Lobby.unity` | 玩家是**场景里的物体、不是预制体**；新场景要么复制一份玩家（两份以后必然走样），要么先做成预制体（改动面很大） |
| **同一个场景、左边搭一间房**（本版） | 玩家只有一份，切大厅/关卡只是换位置；代价是场景文件变大、Hierarchy 多一个 `LobbyRoom` |

所以大厅和关卡**在同一个场景**里，靠 `RoomManager` 的「暂停 / 恢复」把两者隔开。

## 3. 代码结构

| 文件 | 职责 |
| --- | --- |
| `Assets/_Project/Scripts/Lobby/LobbyRoom.cs` | 大厅主控：进/出、走近判定、按 E 交互、底部提示文字 |
| `Assets/_Project/Scripts/Lobby/LobbyPedestal.cs` | 单个角色台：职业数据、立绘、台座、光圈、呼吸动画 |
| `Assets/_Project/_Tuanjie/Editor/LobbyRoomBuilder.cs` | 菜单 **团结 → 生成元气骑士式大厅**，把整间房 + 引用写进 `Game.unity` |
| `Assets/_Project/_Tuanjie/Editor/LobbyRoomCheck.cs` | 菜单 **团结 → 验证元气骑士式大厅**，22 项自检 |

关键入口：

```csharp
// GameBootstrap.HandleScene() —— 每次场景加载完都走一遍
if (ShowLobbyOnStart) _lobby.Enter();   // 进大厅
else                  _lobby.Leave();   // 直接开局

// LobbyRoom
public void Enter();                 // 挪玩家、停战斗、RoomManager.SuspendForLobby()
public void Leave();                 // 恢复战斗、RoomManager.StartRunFromLobby()、放到关卡出生点
public void Select(int index);       // 选中某个台子 → PlayerVisualSwitcher.SetClass()
public bool IsInside / HasChosen / FocusIndex / PortalFocused
```

`RoomManager` 新增两个方法：

```csharp
public void SuspendForLobby()    // _suspended = true；销毁已建好的房间；RoomsCleared 归零
public void StartRunFromLobby()  // _suspended = false；真的建第一间（走房间池、种子、移动玩家）
```

`Start()` 里加了 `if (_suspended) return;` —— 否则进大厅的瞬间会先建一间房、再被大厅收掉，
白算一次种子，`RoomsCleared` 也会先加一再归零。

## 4. 一个坑：读键盘不能用老的 `Input`

第一版 `LobbyRoom.Update()` 里写的是

```csharp
if (Input.GetKeyDown(KeyCode.E)) Interact();
```

自检直接报 `TargetInvocationException`。原因：本工程的 **Active Input Handling = Input System Package**，
老的 `UnityEngine.Input` 一调就抛

```
InvalidOperationException: You are trying to read Input using the UnityEngine.Input class,
but you have switched active Input handling to Input System package.
```

改成新接口，并且对「没有键盘」（批处理、远端机器）做空判断：

```csharp
private static bool InteractPressed()
{
    Keyboard keyboard = Keyboard.current;
    return keyboard != null && keyboard.eKey.wasPressedThisFrame;
}
```

## 6. 排错表

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 按 Play 直接在关卡里，没有大厅 | `ShowLobbyOnStart` 被上一局置成 false，且编辑器没重载域 | 已在 `GameBootstrap.ResetStatics()` 里每次 Play 重置（`SubsystemRegistration`） |
| Update 抛 `InvalidOperationException` | 用了老的 `Input.GetKeyDown` | 改用 `Keyboard.current`（见 §4） |
| 大厅是空的、什么都没有 | 没跑 **团结 → 生成元气骑士式大厅** | 跑一次；它会建 `LobbyRoom` 并写场景 |
| 走到台子前按 E 没反应 | 角色台 `classData` 为空 | 重跑生成菜单，或手动把 `Class_Warrior/Class_Mage` 拖进 `LobbyPedestal.classData` |
| 玩家掉出大厅 | 地板不在 `Ground` 层，或没 `BoxCollider2D` | 重跑生成菜单（脚本会补层与碰撞体） |
| 出发后站在房间里但没怪 | `RoomManager` 仍 `_suspended` | 检查 `Leave()` 是否被调用（`GameBootstrap.StartRun` 会调） |

## 7. 已知限制

1. 大厅和关卡在同一个场景，所以 `Game.unity` 变大了（现在 90 KB 级）；Hierarchy 里多了 `LobbyRoom` 一支。
2. 角色台只有两个（战士 / 法师），加职业要重跑生成菜单或在 Hierarchy 里复制一个台子。
3. 提示文字是屏幕空间贴图文字（中文字形只能运行时加载动态字体），不会跟着角色走。
4. 大厅里没有 BGM / 音效切换（工程还没有音频素材）。
5. 「返回大厅」是重载整个场景，不是无缝切换 —— 会看到一帧黑。
6. 按 E 交互是写死的键，没进改键界面。
