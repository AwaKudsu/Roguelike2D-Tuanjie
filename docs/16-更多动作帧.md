## 2. 为什么只做位移和压缩，不做旋转

一开始想「把挥砍帧转个 15° 就是起手」，实做完发现两个问题：

- **旋转会让像素走样**：像素画是画在整数格上的，转 15° 之后每个像素都要重采样，边缘会糊成毛边，在一个 161px 高的角色上非常明显；
- **旋转会破坏脚底基线**：绕画布中心转会把脚甩离地面，看起来像在飘。要修就得绕脚底转，但那样上半身的位移又对不上。

所以只保留两种变换：**平移**（前后、上下）和**纵向压缩**（绕脚底缩放）。这两种在整数像素上都不产生糊边，而且是真实的动作要素——「蓄力时身体往后坐」「落地时身体往下沉」。

## 3. 动作怎么播：短序列

`WarriorVisual` 原来是一堆 `Sprite` 字段，一刀一张图。现在改成短序列：

```csharp
private Sprite[] _clip;        // 正在播的序列
private int      _clipIndex;
private float    _clipFrameTime;
private float    _clipTotal;
```

**每帧停留时间不是平均分的**，而是按 `0.30 / 0.42 / 0.28` 加权：

```csharp
private static readonly float[] PoseWeights = { 0.30f, 0.42f, 0.28f };
```

命中那一帧占 42% 的时间——玩家真正在意的是「打到了没有」，起手和收招只是过渡。平均分的话命中帧只闪 1/3 的时间，看着像没打到。

序列播完 `_clip = null`，状态机接管（跑动 / 待机 / 空中）。所以序列永远播得完，不会卡在攻击姿势上。

## 4. 每个状态现在长什么样

| 状态 | 帧数 | 说明 |
| --- | --- | --- |
| 待机 | 3 | 0 → 1 → 2 → 1，每 0.62 秒一个节拍，呼吸 |
| 跑动 | 6 | 0 → 1 → 4(压缩) → 2 → 3 → 5(压缩)，帧率按速度 10~20 |
| 劈砍 / 上挑 / 突刺 | 各 3 | 起手 → 命中 → 收招，整段 0.20~0.24 秒 |
| 旋风斩 | 2 轮换 | 蹲扫 ↔ 举砍，每 0.11 秒切一次，配合绕身弧光读作「在转」 |
| 战吼 | 1（按住 0.45 秒） | 举剑怒吼，圆环同时扩散 |
| 冲刺 / 跳跃 / 下落 / 受击 / 死亡 / 胜利 | 1 | 单帧，本来就不需要过程 |

跑动是这一轮手感的重点：原来 4 帧往复（`0→1→2→1`），现在 6 帧顺播，多出来的两帧是**落地压缩**——脚刚落地时身体往下坐 3%，然后弹回来。没有这两帧，跑起来像贴图在滑；有了它，每步都有一个「沉—起」。

> 顺带把 `RunCycle` 删了：往复播会把压缩帧倒着播成「反向落地」，所以跑动改成顺序播 6 帧。

## 5. 技能怎么接到动作上

技能不是靠攻击事件驱动的（战吼压根不打伤害），所以加了两个直接入口：

```csharp
// SkillCaster.CastMelee（duration > 0，即旋风斩）
var visual = GetComponent<WarriorVisual>();
if (visual != null) visual.PlaySpin(skill.duration);

// SkillCaster.CastWarcry
if (visual != null) visual.PlayWarcry(skill.ringDuration > 0f ? skill.ringDuration : 0.45f);
```

`PlaySpin` 会把「攻击序列」清掉并在整个持续时间里轮换两帧——否则旋风斩每 0.2 秒一次的 `Execute` 会触发 `AttackStarted`，把旋转姿势打断成一次挥砍。

## 7. 排错表

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 一刀只有两帧一闪而过 | `slashFrames` 里只有 1 张 | 跑「团结 → 导入战士素材」重新接线 |
| 攻击姿势卡住不结束 | 序列某一帧为空 | 同上；报告里 `序列 | xxx` 那几行会指出缺帧 |
| 跑动脚步像在滑 | 落地压缩帧没接上（还是 4 帧） | 检查 `run` 是否为 6 帧 |
| 待机完全不动 | `idleFrames` 只有 1 张 | 同上 |
| 旋风斩时人物在抽搐 | `PlaySpin` 被 `AttackStarted` 覆盖 | 确认 `OnAttackStarted` 开头有 `if (_spinTimer > 0f) return;` |
| 战吼没抬手 | `SkillCaster.CastWarcry` 里没取到 `WarriorVisual` | 两个组件都挂在 Player 上才取得到 |

## 8. 已知限制

- 派生帧终究是**同一个姿势的位移**，不是真正的新画。挥剑的「刀从右上扫到左下」这条轨迹还是靠弧光（`SlashTrail`）补的，人物本身的剑始终在同一个角度；
- 没有**转身帧**：左右只能靠 `flipX` 镜像，所以披风永远在背对镜头的方向飘；
- 没有**受击方向帧**：被打只有一个跪地姿势，不管是正面挨打还是背后挨打；
- 旋风斩靠两帧交替，读起来是「在动」而不是「在转」；真要转起来得再补 4~6 个朝向帧（背面、侧面、各 45°），那是下一轮的事；
- 帧率上限 20 帧/秒，再高就要考虑把位移改成插值，否则像素在屏幕上会抖。
