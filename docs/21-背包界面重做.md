# Day 25 · 背包界面重做：左边人物与属性，右边分类物品

> 原来的背包是「左边三个装备槽 + 右边一堆格子」，看不出**你是谁、你现在有多强**，
> 找一件武器还得把整包东西从头扫一遍。这一版照《造梦西游》那种布局重排：
> 左上人物立绘、左下属性表、右侧分类标签 + 物品格。

## 2. 三块各自怎么来的

### 2.1 左上：人物

立绘直接用 `ClassData.icon` —— 战士的图标本来就是那张正对镜头的 `Warrior_Idle`，
放大到 150 × 240 当半身像正好。**没填图标就整块隐藏**，不会留一个白框。
职业名在立绘下面，换职业（Esc 菜单里切）时跟着变。

```csharp
ClassData data = stats != null ? stats.Class : null;
_portrait.enabled = data != null && data.icon != null;
_portrait.sprite  = data != null ? data.icon : null;
```

### 2.2 左下：属性表

十行，全部走 `CharacterStats.Get(StatType)`，所以**穿脱装备、换职业、升级强化都会立刻反映**：

| 行 | 取值 | 显示 |
| --- | --- | --- |
| 生命 | `Health.Current` / `MaxHealth` | `122 / 140`（前面红色，后面灰色） |
| 攻击力 | `Attack` | `22` |
| 防御 | `Defense` | `10%` |
| 攻击速度 | `AttackSpeed` | `×0.95` |
| 暴击率 | `CritChance` | `5.0%` |
| 暴击伤害 | `CritMultiplier` | `×1.5` |
| 移动速度 | `MoveSpeed` | `8` |
| 最大法力 | `MaxMana` | `60` |
| 每秒回蓝 | `ManaRegen` | `4` |
| 冷却缩减 | `CooldownRate` | `0%` |

三个「本来就是比例」的项（防御 / 暴击率 / 冷却缩减）直接乘 100 加百分号，
倍率类加 `×`，和提示框里 `StatText.Describe` 的写法保持一致 —— 同一个数在界面上只有一种长相。

`Health` 是**从 `Inventory` 所在的那个物体上拿**的，不是 `FindObjectOfType<Health>()`：
敌人身上也挂着 `Health`，那么写会显示成小怪的血（踩坑 #15）。

### 2.3 右侧：分类标签 + 物品格

分类只有四个：`全部 / 武器 / 护甲 / 饰品`，对应 `_category = 0..3`，
`_category > 0` 时按 `(int)item.slot == _category - 1` 过滤。
标签本身是一个只做转发的组件 `TabButtonWidget`（和 `ItemSlotWidget` 同一个套路），
状态只有一份、在 `InventoryUI._category` 里：

```csharp
public void SelectCategory(int index)
{
    _category = Mathf.Clamp(index, 0, CategoryNames.Length - 1);
    RefreshTabs();
    RefreshGrid();
    RefreshHint();
}
```

格子数量仍然由 `Inventory.capacity` 决定（默认 12 → 6 列 2 行），
超过 `6 × 4 = 24` 格会被截断并在 Console 里警告 —— 界面高度是有限的，
与其让格子画到窗口外面，不如明确说一声。

## 3. 几个刻意的取舍

| 问题 | 处理 |
| --- | --- |
| 背包里穿上一件后，这个分类空了 | 自动跳回「全部」—— 不然你会盯着一个空网格不知道发生了什么 |
| 过滤时点物品会不会穿错 | 不会：点击走的是 `widget.item`，和过滤无关 |
| 大部分装备没有图标 | `item.icon` 为空时用稀有度颜色画一个色块（沿用旧逻辑），所以**名字必须显示**，格子里的空间先给名字 |
| 关掉背包时要不要刷新 | 打开时 `Refresh()` 一次，打开期间靠 `Changed` 事件标脏，关着的时候不画画 |
| 悬停提示框放哪 | 沿用旧逻辑：跟随鼠标、贴边翻转、超出窗口就夹回来 |
| 底部提示条铺满整行会怎样 | 会从属性卡底下穿过去，和最后一行数字叠字 —— 所以它只占右侧 740 宽 |
| 提示条贴着窗口下边框会怎样 | 会被边框切掉一截（第一版放在 −334）。现在放到网格下方 −286，四周都留白 |
| 装备槽比角色卡还暗 | 卡片底色 0.13、格子 0.11，等于没画。格子必须**亮过**卡片，0.17 起才看得出是三个槽 |

## 4. 换皮：把素材大师的九宫格图接进来

界面是代码搭的，图片进不了代码常量，所以走「两个序列化字段 + 一个菜单」：

```
InventoryUI
├─ panelSprite  九宫格窗口图（UI_Panel.png）→ 主窗口、提示框
└─ slotSprite   九宫格格子图（UI_Slot.png） → 物品格、装备槽、标签、两张卡片、立绘框
```

接法：菜单 **团结 → 接 UI 美术**，它 `FindObjectOfType<InventoryUI>(true)` 后直接写这两个字段（`WireUi()` 在 `UiArtImporter.cs` 里）。

**留空就退回纯色块**，不是空白 —— 每个调用点都带一个 `fallbackColor`：

| 位置 | 有图 | 没图 |
| --- | --- | --- |
| 主窗口 | `NewFramed(panelSprite)` + 内层 35% 压暗 | 描边色 + `WindowBg` |
| 两张卡片 / 立绘框 | `slotSprite`，立绘框偏暖金 | `CardBg` / 深灰 |
| 物品格 | `slotSprite`，空槽压暗到 55% | `CellBg` / `EquipCellBg` |
| 标签 | 选中金 `(0.92,0.78,0.46)`、未选中压暗 | `TabSelected` / `TabBg` |

**标题字色不能跟着底色走**。第一版把选中标签的字改成深色（想着「金底配深字」），结果九宫格图中间是深蓝黑，
选了「全部」之后那一格看着像空的。现在字一律浅色，只让底色偏金 —— 对比度靠底色给，不靠字色。

**没有图标的物品改成「小宝石」**。以前是 36×36 铺满格子的纯色方块，四个格子一排全是浅色块，看着像占位符没做完。
现在换成 24×24 的稀有度色方块（`ItemSlotWidget.gem`），周围留出格子的深底，颜色只当点缀。


**有图之后不能再拿纯色盖上去**。旧代码遇到悬停/选中是直接 `background.color = CellHover`，那会把金边框一起涂成一块米色。现在分两条路：有图只改**色调**（金色 = 悬停/选中），没图才换纯色。

`Image.type` 也有讲究：`sprite.border` 非空才用 `Sliced`，否则退回 `Simple` —— 对没有边框信息的贴图硬用 Sliced，Unity 会静默退化成 Simple，调试时容易以为「九宫格没生效」。

## 5. 左键菜单与金币

左键不再「点了就执行」，而是先弹一张 236×196 的小菜单：**主操作 + 出售 + 取消**。

| 点的地方 | 主操作 | 第二行 |
| --- | --- | --- |
| 背包里的装备 | 装备 | 出售 +N 金币 |
| 背包里的消耗品 | 服用 +N 生命 | 出售 +N 金币 |
| 身上的装备槽 | 卸下 | 出售 +N 金币 |

菜单的位置是算出来的：`RectTransformUtility.WorldToScreenPoint` 把格子换成屏幕坐标，
再 `ScreenPointToLocalPointInRectangle` 换算到窗口坐标，默认开在格子右下 16px；
靠近窗口右/下边缘时翻到另一侧，所以点最后一列也不会跑到窗口外。

金币加在 `Inventory` 上（`Gold / AddGold / TrySpendGold` + `GoldChanged` 事件），
卖价由 `ItemData.SellPrice` 决定：填了 `price` 就用它，否则按稀有度给 8 / 20 / 50。
底部提示条上实时显示金币，卖出后立刻变。

开局会塞 2 瓶「生命药水」进背包（`Inventory.startingPotions`）——
用运行时 `CreateInstance<ItemData>()` 造，而不是新建 `.asset`：
团结引擎 `.meta` 里的 guid 是 base64 形式，手写资产文件很容易和场景引用对不上。

## 6. 已知限制

1. 属性表不区分「基础值 / 装备加成」。想做「+6 攻击力」绿色高亮，需要让
   `CharacterStats` 额外暴露一份「不含装备的裸值」，现在没做。
2. 没有排序和搜索。物品不多（12 格）时够用，等背包扩容到 40 格以上再补。
3. 立绘是静态图，不播待机动画 —— 和大厅里那张静止帧是同一张。
4. 九宫格图的边框偏粗：窗口 1180×720 上还能接受，但格子只有 96×96，
   `UI_Slot` 的边（50px / PPU 640 ≈ 8 UI 像素）在小格子上占了近十分之一。
   真要更精细，得给格子单独出一张边更细的图。
5. 换皮只换了「框」，没换「内容」：稀有度色块、文字排版还是代码画的。
6. 金币只出不进：卖东西加钱，还没有商店/掉落能花钱，`TrySpendGold` 现在是空跑。
7. 左键菜单固定三行，将来物品能做的事变多（重铸、镶嵌）要改成动态行数与高度。
